# Glossário

- **SLO**: meta de confiabilidade que o time se compromete a cumprir, como 99,9% de disponibilidade no mês.
- **Error budget**: quanto de indisponibilidade ainda cabe dentro do SLO. Acabou o orçamento, o deploy de funcionalidade para.
- **Rollback**: voltar para a versão anterior de um deploy.
- **Postmortem**: documento escrito depois de um incidente, com a linha do tempo, a causa e as ações.
- **Canary**: liberar uma versão nova para uma fração pequena do tráfego antes de liberar para todos.
